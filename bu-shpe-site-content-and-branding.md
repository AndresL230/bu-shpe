## 3. BRANDING -- SHPE NATIONAL (Official Guidelines v6)

### 3a. Color Palette

| Name | Hex | RGB | Pantone | Usage |
|------|-----|-----|---------|-------|
| **Navy** | `#001F5B` | 0, 31, 91 | PMS 281 | Primary dark / wordmark / backgrounds |
| **Orange** | `#FD652F` | 242, 101, 52 | PMS 1655 | Accent / energy / CTA |
| **Red** | `#D33A02` | 210, 63, 38 | PMS 485 | Logo mark element |
| **Blue** | `#0070C0` | 24, 112, 184 | PMS 660 | Logo mark element / links |
| **Pale Blue** | `#72A9BE` | 114, 170, 190 | PMS 7695 | Secondary / subtle accents |
| **Gray** | `#626366` | 98, 99, 102 | PMS 446 | Body text / secondary text |

**Convention-specific additions (for inspiration):**
- Cream: `#FCF0D6` (warm backgrounds)
- Pale Orange: `#EF9260` (soft accent)
- Red (alt): `#C24E3A` (deeper red accent)

### 3b. Typography

**Primary Font:** Univers LT Std
- Headlines: Univers 67 Bold Condensed or Univers 57 Condensed
- Body: Univers 55 Roman
- Light: Univers 45 Light

**Fallback Stack:**
1. Franklin Gothic
2. Helvetica
3. Arial

**Free/Web Alternatives (for web use):**
- Headlines: Use a bold condensed sans-serif (e.g., Barlow Condensed, Oswald, or similar on Google Fonts)
- Body: Use a clean sans-serif (e.g., Source Sans 3, DM Sans)

### 3c. Logo

**Logo Elements:**
- Four swirling shapes representing: interconnectedness of community, SHPE's 4 core values (Familia, Service, Education, Resilience), and STEM
- Colors: red, orange, two shades of blue
- Two blue marks form an abstract "S"

**Logo Variants:**
- Horizontal layout (primary, preferred)
- Vertical layout (for square/thin spaces)
- Logomark only (only when "SHPE" name is displayed nearby)
- Color on white, white on navy, white on other colors, solid navy

**BU Chapter Logo:** `SHPE_logo_horiz_Boston-University_DKBG.png` (dark background version exists)

**Min sizes:** 150px digital, 1.25" print

### 3d. Core Values

**Familia | Service | Education | Resilience**

### 3e. Language Guidelines

- Use "Hispanic" (not Latina/Latino/Latinx per national guidelines)
- Use "STEM" (not STEAM or STEM+CS)
- Note: BU chapter site uses "Latinx" in some places -- decide on consistency

### 3f. Photography/Imagery Guidelines

- People at the center
- Tone: open, engaged, energetic, diverse
- Mix of male/female, student/professional
- Should not look staged
- One subject over many preferred
- Don't overcrowd with type
